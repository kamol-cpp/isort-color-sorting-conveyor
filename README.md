# iSort — Color-Sorting Conveyor

**Status:** Completed · September–December 2025  
**Area:** Mechatronics, automation

An automated conveyor for RGB object detection and sorting.

## Engineering work

- Designed 12 V and 5 V power paths to separate actuation and logic loads.
- Developed microcontroller logic integrating RGB/IR sensors, DC motor drive, and servo-actuated sorting.
- Modeled the system in SolidWorks and created wiring diagrams and control flowcharts.
